# 🎮 Hangman Word Guessing Game

A console-based Hangman game developed in Python as part of my Python internship at Datheon.

## ✨ Features

- Random word selection from an external word list.
- Six incorrect attempts per game.
- Letter-by-letter word guessing.
- Duplicate guess detection.
- Input validation.
- ASCII Hangman drawings.
- Win and loss messages.

## 🛠️ Technologies Used

- Python
- VS Code

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Keep `hangman.py` and `words.txt` in the same folder.
4. Open a terminal in that folder.
5. Run:

```bash
python hangman.py
```

## 📁 Project Files

- `hangman.py` — Contains the game logic.
- `words.txt` — Contains the word list used by the game.
